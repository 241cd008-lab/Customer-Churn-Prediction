# Customer Churn Prediction

## Project Overview

Customer Churn Prediction is a machine learning-based web application developed to predict whether a customer is likely to leave a service. It uses customer details, service usage and billing information to predict churn.

## Objectives

* Analyze customer data.
* Apply machine learning algorithms for churn prediction.
* Compare Logistic Regression and Random Forest models.
* Predict customer churn probability.
* Store prediction history using SQLite.
* Display results through an analytics dashboard.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Flask
* HTML, CSS, JavaScript
* Bootstrap
* SQLite

## Machine Learning Models

* Logistic Regression
* Random Forest Classifier

## Features

* Customer details input form
* Churn prediction and probability
* Model comparison
* Analytics dashboard
* Prediction history stored in SQLite

## How to Run

1. Clone the repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Run `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.

## Project Purpose

This project demonstrates the application of machine learning in customer analytics and churn prediction.
